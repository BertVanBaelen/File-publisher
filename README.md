## File Links

Upload files in Home Assistant and serve them under clean public paths, like
`files.vanbaelen.dev/resume`. Point a Cloudflare tunnel at the add-on's port and
only the files you've linked are reachable. Your Home Assistant stays private.

See [file_links/DOCS.md](file_links/DOCS.md) for setup.
